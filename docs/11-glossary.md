# Technical Glossary: Amazon Clone

- **BaaS (Backend-as-a-Service)**: A cloud computing category where third-party providers (like Firebase) manage servers, databases, and authentication APIs.
- **CardElement**: A secure, PCI-compliant input field provided by Stripe Elements that collects credit card credentials without exposing them to the host application.
- **Cloud Firestore**: A flexible, scalable NoSQL document database offered by Google Cloud Firebase.
- **Context API**: React's built-in mechanism for sharing global values across components without explicit prop passing.
- **PaymentIntent**: A Stripe API object representing a payment lifecycle from initiation to capture and settlement.
- **useReducer**: A React hook for managing complex state transitions via pure reducer functions.
