Every single item from Section A through Section R is rigorously evaluated for **Amazon Clone (45-amazon-landing-page)** across seven mandatory dimensions:
1. What it is
2. How it is done in this project (file, function, line)
3. Why this choice
4. Alternatives and why not each one
5. What can fail and how it is handled
6. How it is tested
7. What I would change
