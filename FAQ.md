# Frequently Asked Questions: Amazon Prime E-Commerce Showcase

### 1. What is Amazon Prime E-Commerce Showcase?
Responsive e-commerce storefront landing with product carousels and checkout UI layouts.

### 2. What technology stack does it use?
Built with HTML5, CSS3 (Flexbox/Grid), Vanilla JavaScript.

### 3. Where is this project deployed?
Hosted live at: https://avishjain9.github.io/39-amazon-landing-page/

### 4. How can I run it locally?
Follow the installation and setup guide provided in [docs/SETUP.md](docs/SETUP.md) or the repository `README.md`.
